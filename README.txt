Local preview:
1. Keep index.html and assets/ together.
2. Open index.html in a browser or run a local static server.
3. Open certifications.html for the dedicated certificates page.

Vercel:
Deploy this folder as a static site. No build command or output directory is required.

Before deploying, replace the [BRACKETED PLACEHOLDERS] in index.html:
- Add the resume PDF.
- Add the Pastry Project repository, role, team size, your specific contributions, and verified results.
- Add a Flutter mobile screenshot.
- Add an experience / leadership entry and certificate or seminar links.
- Configure the Formspree form ID so the contact form can send messages.

The portfolio and certifications page share the saved light/dark theme. The ConvergeIT 2026 and AI and Blockchain 2026 certificate images, along with other portfolio assets, are stored in assets/.
